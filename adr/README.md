# Architectural Decision Records (ADR)

This module contains a collection of Architectural Decision Records (ADRs) which have been made during the
development of the project. It consists of a collection of markdown files, each of which describes a single
ADR - a single topic or a theme that we decide to review, investigate, discuss, and make decision upon. 

The ADRs are numbered sequentially, and are stored in directories (because we might include diagrams or other resources
along the markdown file) each dedicated to a major part of the project.

The ADRs here are written for the project-specific practices and decisions.
